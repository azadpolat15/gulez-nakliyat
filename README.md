# Gülez Nakliyat

Derince / Kocaeli merkezli Gülez Nakliyat'ın web sitesi. Saf HTML, CSS ve JavaScript; kurulum gerektirmez.

- **Ana sayfa** (`index.html`): kaydırdıkça gündüzden geceye dönen, katmanlı parallax site.
- **Sade sürüm** (`nakliyat-sitesi/`): aynı içeriğin daha sade, scroll animasyonlu sürümü.

## İşletme bilgilerini değiştirme

Telefon, WhatsApp, adres, Google puanı gibi bilgiler her sitenin `script.js` dosyasının en üstündeki `CONFIG` bloğundadır. Orayı değiştirmeniz yeterli; sitedeki tüm butonlar ve yazılar otomatik güncellenir.

## Yerelde açma

`index.html` dosyasını tarayıcıda açın.
